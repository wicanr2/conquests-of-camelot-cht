# 《亞瑟王傳奇》翻譯指令（給每一個翻譯批次）

> **動手前先讀完整份，再讀 `names.tsv`。**
> 如果你手邊有《宇宙傳奇》(Space Quest) 系列的翻譯守則，那份的**語氣守則對本作全部作廢**。
> 那邊是惡搞科幻喜劇，這邊是亞瑟王史詩正劇。照抄會毀掉整個作品。

---

## 一、定位一句話

**莊重、有距離感的中世紀騎士史詩，第二人稱敘事，不插科打諢。**

玩家扮演**亞瑟王本人**。主題是信仰、忠誠、背叛與贖罪——皇后昆海兒與蘭斯洛特的私情
為王國招來詛咒，三位騎士出尋聖杯一去不返，亞瑟親自上路。死亡不是笑點，是失敗與代價。

## 二、語氣對照

| 面向 | 這樣寫 | 不要這樣寫 |
|---|---|---|
| 敘述 | 你伸手觸碰石壁，指尖傳來一陣寒意。 | 你手一摸，冷得要死。 |
| 死法 | 你的旅程在此終結。 | 你就這樣掛了／變成一張人肉煎餅 |
| 拒絕 | 此舉並無意義。 | 想都別想／你是有事嗎 |
| 語氣詞 | （盡量不用） | 喔、啦、耶、欸 |
| 人物稱謂 | 陛下、爵士、吾王、汝 | 老兄、你這傢伙 |
| 句長 | 可以長句，講究節奏 | 短句斷開、一句一件事 |

### 分寸

**莊重不等於文言文。** 目標是「中文歷史劇的口白」，不是《三國演義》原文。
判準：唸出來像不像**中文配音的歐洲歷史劇**——像新聞稿或說明書就太乾，
像武俠小說就太遠，出現「之乎者也」就過頭了。

- 人物對白可以有身分差異：亞瑟王莊重、平民直白、僧侶掉書袋、反派尖刻。
- 旁白（第二人稱「你」）保持敘事者的距離，不評論、不吐槽。
- 原文的中世紀語感（`Aye`、`Nay`、`'Tis`、`thee`、`thou`、`m'lord`）用中文的對應語域處理：
  「是的」→「正是」；「不」→「不可」「休得」；`m'lord`→「吾王」「陛下」（看說話者身分）。
  **不要每個 `Aye` 都翻成「唉」**——那是 yes。

## 三、[HARD] 這是 parser 遊戲：看到的翻，打字輸入的留原文

玩家要用鍵盤打英文指令（`look`、`ask about grail`、`buy herb`）。因此：

1. **敘述、對白、提示訊息 → 翻譯。**
2. **玩家必須原樣打進去的字串 → 保留英文。** 若一句話在教玩家打什麼，
   譯文要把那個指令**維持 ASCII 原樣**，例如：
   「用『`ask about grail`』向他打聽聖杯的下落。」
3. **打字硬關**：玩家必須打對英文才過的關卡，譯文問句後**就地補上英文答案**，維持 ASCII：
   - 湖中女神：必須打 `Love is my shield`
   - 謎語石、神奇花叢、符號考驗、維納斯問答：答案都是英文單字
4. **謎語要改寫，不能直譯。** 直譯的英文謎語在中文裡無解，等於卡關。
   中文謎面要讓玩家**靠中文推得出那個英文答案**，必要時重寫謎面，
   並在謎面後標註答案的英文拼法。遇到謎語**先標記出來**，不確定就留原文加註記，
   不要硬翻。

---

## 四、[HARD] 用字紅線

- **不要簡體字。** 非 Big5 的字會讓**整則譯文被丟棄**，實機直接顯示英文（不是只掉那個字）。
- **不要中國大陸用語**：視頻、質量、信息、軟件、網絡、屏幕、默認、菜單（指軟體選單）、
  鼠標、內存。（「程序」若指 procedure、「一會兒」都是正常繁中，不必改。）
- **標點用全形**（，。！？：；「」『』……——），但**控制序列與英文片段內的半形符號不要動**。

## 五、[HARD] 機械規則（違反會顯示錯字或崩潰）

1. **第一欄英文原文一個字都不能改** —— 那是遊戲查表用的 key。
2. **控制序列原樣保留**，數量與相對位置都不能變：`%s` `%d` `%3d` `\n` `%v` 之類。
   例：`%3d/368  Skill Points\n\n%3d/293  Wisdom Points \n\n%3d/358  Soul Points`
   → `%3d/368  技能點數\n\n%3d/293  智慧點數 \n\n%3d/358  靈魂點數`
   （`%3d` 保留、`\n\n` 保留、`Wisdom Points ` 尾端那個空格也保留）
3. **行首行尾空白照抄** —— 有些字串刻意用空白對齊排版。
4. **長度控制在原文的 ±30%**。對話框只有約 14 個英文字元寬，中文更擠。
5. **輸出是 TSV：`原文<TAB>譯文`，行數與輸入完全相同**，不要增刪行、不要加說明。

## 六、譯名

**一律照 `names.tsv`，不要自己另譯。** 那份表來自《軟體世界》第 18、19 期當年的攻略，
是 1990 年代台灣玩家實際看到的名字。幾個最常出錯的：

| 英文 | 中文 | 注意 |
|---|---|---|
| Camelot | **肯萊特** | 不是「甘美特」「卡美洛」 |
| Gwenhyver | **昆海兒** | 不是「桂妮薇兒」 |
| Excaliber | **聖劍** | 遊戲拼法就是 Excaliber |
| Gawaine | 高文 | |
| Launcelot | 蘭斯洛特 | |
| Galahad | 葛拉漢 | |
| Saracen | 撒拉遜武士 | |
| Mithras | 米夏拉 | |
| Aphrodite | **阿芙羅黛蒂** | 不可譯成「維納斯」——遊戲裡 Venus 另有其詞，兩者會同句出現 |
| Venus | 維納斯 | |
| Forest Perilous | 派瑞樂斯森林 | |
| Glastonbury Tor | 格列斯登伯利山 | |

表上沒有的宗教／神話專名，**查通行中譯，不要自創音譯**（玩家對「耶路撒冷」「加百列」
有既定認知，自創音譯會讓正劇氣氛垮掉）。查不到才音譯，並回報給主流程登錄。

## 七、[HARD] 譯前先確認「這句在遊戲裡是什麼情況」

最容易出錯也最傷玩家的是講機關、解謎、因果的句子。**解謎句要先弄清楚機關實際怎麼運作再下筆**
——因果講反，玩家照著讀會卡關。

本作還多一層：**道德選擇會影響靈魂點數（Soul）**。翻錯選項的語氣可能讓玩家選錯，
而那會影響結局。這類句子要特別小心。
